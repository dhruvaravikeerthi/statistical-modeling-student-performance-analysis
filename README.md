# Overview

This project is a system that uses machine learning to analyze and predict how well students will do in school. It looks at things like how hours students study, how much they sleep and how often they go to class. The system also checks how stressed students are and other important things. Then it uses this information to guess how well students will do in school.
It compares this guess to the score that the student wants to get. The system gives the student feedback based on the results. The main goal of this project is to see how machine learning can help us understand how student habits affect their grades.

# Key Idea
The system learns from student data and uses this knowledge to make predictions about new students. It does the following things:
* predicts how well students will do in school
* Compares this prediction to the score the student wants
* Finds areas where students need to improve
* Gives students advice on how to do
* Shows students which things affect their grades the
